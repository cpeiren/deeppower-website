Capabilities/TradeControl/Research

Research that improves itself.

TradeControl research runs on our proprietary agent framework. After each round, a dream session reviews every result and rewrites what the agents know, so each round starts smarter than the last. Proven by a live track record on six commodity exchanges.

The loop
  1. 01ProposeSpecialist agents for each sector and data type read the data and propose ideas.
  2. 02Build and auditOne agent writes the signal. A second audits the code for look-ahead and data errors.
  3. 03TestA statistical scorecard decides. The signal must add something the library does not already know.
  4. 04TradeKept signals go into the live book, where their results are compared with what the backtest expected.
  5. 05DreamA dream session reviews every verdict and its cause, then rewrites what the research agents start from.

Then the loop runs again, from a better starting point.

What a dream changes

Most research systems get faster. Ours gets better at research. Each dream session turns the last round of results into the next round's instructions.

  • 01What worksThemes that keep passing are found and pushed further.
  • 02What failsFailure modes and code bugs are written down, so no agent repeats them.
  • 03What is leftUntried data and methods are queued as the next frontier.
  • 04What never changesA short set of hard rules, written by people, that no dream can override.
Proven live

The framework is proprietary and built in-house. It runs the research behind every strategy we trade on six commodity exchanges, from daily fundamental signals to intraday order-book signals. In one fundamental pipeline, the agents read 82 datasets and tested 594 ideas. 430 were rejected.
