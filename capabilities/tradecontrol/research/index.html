Capabilities/TradeControl/Research pipeline

Every idea is tested before it trades.

One research pipeline serves every strategy we run, from daily fundamental signals to intraday order-book signals. Agents propose ideas, then try to break them.

Where it runs
  • 01Fundamental signalsDaily signals from supply, demand, inventory, trade and weather data, across agriculture, chemicals, energy and metals.
  • 02Intraday signalsShort-horizon signals from the order book and trade flow, researched and audited the same way.
  • 03New sectorsA new market needs its data and a specialist agent. The audit, the tests and the rules stay the same.
The pipeline
  1. 01SourcesWhatever the strategy needs: government statistics, exchange reports, weather, prices or full order books.
  2. 02Point-in-time storeEvery record keeps the time it became available. A backtest sees only what was known at that moment.
  3. 03Research agentsSpecialist agents for each sector and data type read the data and propose ideas.
  4. 04Code and auditOne agent writes the signal. A second audits the code for look-ahead and data errors before any result is computed.
  5. 05Statistical gatesA backtest scorecard decides. The idea must add return that the existing signals do not already explain.
  6. 06Signal libraryKept signals feed portfolio construction and then the trading book. Each is re-audited as new data arrives.

Rejected ideas stay on record with the reason, so the agents do not try them twice.

What survives

An agent that tests hundreds of ideas will find some that worked by chance. The pipeline is built to reject those. Four rules do most of the work, in every sector and at every horizon.

  • 01No future dataSignals are built from the point-in-time store, so a number revised in March cannot leak into a January decision.
  • 02Separate auditorThe agent that writes a signal never approves it. A different agent checks the code, and a third judges the results.
  • 03Must add somethingA signal that repeats what the library already knows is rejected, however good it looks alone.
  • 04Sealed pricesThe most recent prices are locked away from the agents and used only for a final check by a person.
